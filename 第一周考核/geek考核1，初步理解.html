11.19对geek的理解和对GitHub的初步探索-ymj

geek：
对计算机技术充满热情，好奇底层原理，不断探索技术。
geek精神：
1.好奇：弄清代码的运行过程和底层原理。
2.开源：将自己的思考分享到社区，共同进步。
3.完美主义：不断优化代码，寻找更准确更省时的解决方案。
4.实践：不确定的时候写写看。

GitHub 核心定位：
GitHub 是全球最大的‌代码托管与开源协作平台‌，基于Git版本控制体系搭建，开发者可以在这里存储、管理、分享代码，也能参与全球各类开源项目的共建，是程序员日常协作、技术沉淀的核心工具。

核心概念理解：
‌Fork‌：相当于在自己账号下“复刻”一份别人的公开仓库副本，你可以在自己的副本里自由修改代码，不会影响原项目，是参与开源项目的第一步。
‌Pull Request（PR）‌：你在自己Fork的副本里改完代码后，向原项目维护者发起的“合并申请”，对方可以审核你的修改、讨论细节，最终决定是否把你的改动合并进原项目，是开源协作的核心流程。

网页打不开的体验：
有的，打开的时候网页经常崩溃，切换镜像了。

这份文档为什么规范：
每一个问题都分段回答了，而且句子都比较短，便于阅读。
