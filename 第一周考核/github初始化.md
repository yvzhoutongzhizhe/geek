# github初始化

1. 创建方式
创建了一个与 GitHub 用户名完全相同的公开仓库（例如  yulongshizhe/yulongshizhe ），并初始化了 README，它会自动展示在个人主页。

2. 参考的优秀案例

https://github.com/abhisheknaiidu/awesome-github-profile-readme

https://github.com/matiassingers/awesome-readme

3. 我学到了哪些美化技巧？

插入动态徽章（Badges）：使用  shields.io  网站生成各种颜色的技能标签（如 Python、HTML5 徽章），让主页看起来更专业。

展示统计数据：利用 GitHub Actions，可以自动生成自己的提交记录热力图、语言比例图或星星收集图。

使用 Markdown 排版：通过合理的表格（Table）布局、折叠标签（<details>）和引用块，让主页信息井井有条，不显得杂乱。
